### Featured Project

**🚦 ESP32-S3 Ultrasonic Traffic Light Controller**
A non-blocking, finite-state-machine-based traffic signal controller using an ESP32-S3 and an HC-SR04 ultrasonic sensor to actuate signal timing based on real-time vehicle presence, rather than fixed timers. Validated in SUMO (Simulation of Urban MObility) against baseline fixed-timing control. Currently being developed into a research paper evaluating ultrasonic threshold-based actuation and its failure modes compared to camera/ML-based alternatives.

`ESP32-S3` `C++` `Embedded Systems` `FSM Design` `Sensor Integration` `SUMO Simulation`
